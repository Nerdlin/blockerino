## 🎮 Что нового и улучшено

### Обновления приложения (Android)
- Уведомление «Доступно обновление» теперь показывается **при каждом запуске**, **при возвращении в игру** (раз в 15 минут) и **каждые 30 минут, пока игра открыта** — а не один раз за сессию. Когда вы выпускаете новую версию, игроки с любой старой версией увидят её при ближайшем заходе.
- Одно и то же окно не повторяется в одной сессии, но более новая сборка покажет его снова.
- Ручная проверка в «Настройки → Обновления» осталась и всегда показывает результат.
- Тексты окна обновления переведены (русский / английский).

### Достижения
- Пиксельные иконки достижений одинаково выглядят в вебе, Discord и мобильном приложении (медали-эмодзи заменены).
- Всплывающее окно с анимацией и звуком при получении достижения, как в Steam.
- Список достижений обновляется автоматически, кнопка «Refresh» осталась.

### Мини-игры
- **Sea Battle:** новый дизайн кораблей «пером на клетчатой бумаге» (щит-одноклеточник, заострённые корпуса с башнями); исправлен перенос сетки на узких экранах; **кнопка «кубик» (случайная расстановка) больше не ломает поворот кораблей**.
- **Durak Online:** ползунок ставки учитывает баланс — от минимальной ставки до вашего баланса (логарифмическая шкала для больших балансов), кнопки Min / Half / All in, пиксельные иконки режимов, монет и кубика.
- Иконки рангов в ELO-рейтингах (бронза, серебро, золото, алмаз, звезда, корона) теперь пиксельные и одинаковые в обоих рейтингах.

### Друзья и аккаунты
- Поиск друзей показывает **подсказки при вводе**; при нескольких похожих именах игрок выбирает из списка, а не добавляется первый попавшийся.
- В окне ввода ника (Versus и конец игры) для гостей добавлено предложение **«Создать аккаунт» / «У меня есть аккаунт»**.
- Исправлена причина дублей аккаунтов при входе через Discord Activity: теперь функция находит аккаунт, к которому уже привязан Discord (см. «Развёртывание»).

### Большие экраны
- Окна меню и игр масштабируются на десктопе (до 760 px в ширину и 92% высоты); поле Sea Battle растёт вместе с окном, а игровая доска на экранах 900×900+ крупнее (блоки до 64 px).

## 🛠 Развёртывание (после публикации APK)

1. Применить миграцию `supabase/migrations/20261016120000_find_user_by_discord_identity.sql` (`npx supabase db push`).
2. Задеплоить функцию: `npx supabase functions deploy discord-activity-auth`.
3. **После** загрузки APK в GitHub Releases обновить запись `android_version` в `app_config`, чтобы игроки получили уведомление:

```sql
UPDATE public.app_config
SET value = jsonb_build_object(
  'latestVersion', '1.0.7',
  'latestBuildNumber', 8,
  'downloadUrl', 'https://github.com/Nerdlin/blockerino/releases/download/v1.0.7/blockerino-1.0.7.apk',
  'releaseNotes', 'Pixel icons, achievement popups, new Sea Battle ships, smarter Durak bet slider, friend search suggestions and more.',
  'isMandatory', false
)
WHERE key = 'android_version';
```

> Если применить `UPDATE` через дашборд или MCP, версия миграции в базе должна совпадать с именем файла (см. `supabase/MIGRATIONS.md`).
