# Blockerino 1.0.5

**Стабильная нативная сборка для Android с исправлением краша при запуске.** Классический геймплей и ретро-стиль сохранены.

## 🎮 Что нового и исправлено

- **Критическое исправление краша на Android:** Устранён сбой при старте приложения (`Cannot read property 'location' of undefined`), возникавший из-за несовместимости веб-хука Discord Activity с нативным окружением React Native.
- **Исправление свечения сетки на мобильных устройствах:** Устранена проблема, из-за которой пустые клетки сетки на Android получали стили скинов блоков (`piece_circuit` и др.) и внутренние тени `boxShadow`, вызывавшие яркое неоновое свечение. Пустые ячейки теперь всегда используют чистый стиль без теней и возвышений (`elevation: 0`).
- **Предотвращение выхода комбо-текста за рамки:** Всплывающие надписи очков и комбо (`ScorePopup`) теперь строго привязаны к координатам игрового поля и ограничены по горизонтали и вертикали. Добавлено масштабирование текста (`adjustsFontSizeToFit`), а высота взлета ограничена, благодаря чему надписи комбо больше не выходят за границы игрового поля и экрана.
- **Поддержка Discord SDK:** Добавлена строгая проверка платформы (`Platform.OS === 'web'`), обеспечивающая гладкий запуск на Android без потери интеграции с Discord на вебе.
- **Инфраструктура Gradle:** Исправлена конфигурация Gradle wrapper и скриптов запуска с привязкой к JDK 17, увеличен тайм-аут сетевых загрузок.
- **Обновление версий:** Кодовая база синхронизирована на версии 1.0.5 (`versionCode: 6`) в `app.json`, `build.gradle` и `package.json`.

## ✅ Проверки
