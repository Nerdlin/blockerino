# Blockerino 2.0.1

**Шахматы как на chess.com: контроль времени с часами, рейтинг Elo, боты с характером, вызовы друзей и поиск соперника. Новые ежедневные задания.**

Это обновление внутри линейки 2.0. Нативных изменений нет, `runtimeVersion` остаётся `2.0.0`, поэтому установленные 2.0.0 могут получить JS-часть и по воздуху.

## 📥 Скачать

- APK: `blockerino-2.0.1.apk` · сборка 13
- AAB: `blockerino-2.0.1.aab` · сборка 13 (для Google Play Console)

Размеры и SHA-256: см. раздел «Артефакты» ниже.

## 🎮 Что нового

### Шахматы
- **Контроль времени:** пуля, блиц, рапид, выбор «Время» с раскрывающейся панелью и своим временем (ползунки минут и добавки).
- **Часы, сдача, ничья, отмена партии, выбор фигуры при превращении, PGN.**
- **Рейтинг Elo** по классам (пуля / блиц / рапид), старт 1000, хранится на сервере.
- **Боты** с фиксированным Elo и адаптивный Echo, пиксельные лица, новые боты открываются победами.
- **Вызов друга** и **поиск случайного соперника** по рейтингу; Quick Match также в Versus 1v1.
- Меню в стиле chess.com, пиксельные иконки, плавное движение фигур с подсветкой шаха, синтезированные звуки (ходы, взятия, шах, рокировка, превращение, результат, тик при малом времени).

### Остальное
- Ежедневные задания: пул из 28 видов, меняются каждый день.
- «Другие игры»: первыми идут шахматы и Дурак.
- Ссылка на GitHub в «О игре».
- Название в магазине: Blockerino: Pixel Duels.

## 🧪 Проверки
- `npx tsc --noEmit` без ошибок, `npx jest` 58 наборов / 345 тестов.
- `npm run db:check`: все SQL-тесты PASS (включая chess_ratings, chess_matchmaking, chess_friend_ratings, daily_quests).
- `npm run e2e:chess-rpc`: серверные проверки пройдены.
- Не проверено вживую: игра двух устройств через поиск/вызов, звуки на телефоне, миграции на боевой базе.
