# Blockerino 1.0.4 — Android (build 5)

Обновление APK с сохранением текущего пиксельного оформления.

- Исправлены выход участников из лобби «Дурака», освобождение места до раздачи и завершение ожидания после выхода хозяина.
- После начала партии новый клиент не может занять место выбывшего игрока; ожидающий подтверждения клиент не отменяет чужую партию при выходе.
- В голосовании за реванш учитывается инициатор, новая партия использует исходный размер колоды.
- В APK включены ранее внесённые исправления игровых режимов, синхронизации локальных рекордов и распределения мест в «Дураке» на 3–6 участников.
- Нативный Android-проект обновлён под установленный Expo 54 / React Native 0.81; убрана привязка Gradle к локальному пути Java.

Проверки: 82 теста в 17 наборах, TypeScript, успешная облачная release-сборка. В браузере проверены подключение, выход и повторное подключение в лобби на троих, отмена комнаты хозяином и компоновка настроек на ширине 390 px.

APK содержит arm64-v8a, armeabi-v7a, x86 и x86_64. Сертификат подписи совпадает с опубликованным APK 1.0.3; номер сборки повышен с 4 до 5. Установка поверх прежней версии на физическом устройстве ещё не проверена. Полный вход внутри Discord Activity и полные партии на 3–6 реальных устройствах также не подтверждены этим выпуском.
