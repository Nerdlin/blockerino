## 🎮 Что нового и улучшено

- **Встроенная система автообновления:**
  - При запуске игра автоматически проверяет наличие новых версий в облаке Supabase. Если доступна новая версия, игроку предлагается обновиться в один клик.
  - В меню настроек («Settings / Настройки») добавлен раздел **«Обновления» / «Updates»** с отображением текущей версии `1.0.6 (build 7)` и кнопкой ручной проверки обновлений.
  - Исправлен обработчик ссылок загрузки APK через `Linking.openURL` для гладкой загрузки на всех версиях Android.
- **Оптимизация базы данных Supabase Free Tier под наплыв игроков:**
  - Созданы и применены частичные B-tree индексы (`idx_profiles_elo`, `idx_profiles_highscore_classic`, `idx_profiles_highscore_chaos`, `idx_profiles_highscore_time_attack`, `idx_profiles_highscore_daily`, `idx_profiles_lower_player_name`).
  - Устранены тяжелые полные сканирования таблиц (Full Table Scans) при открытии лидербордов. Нагрузка на CPU базы снижена более чем на 95%.
  - Проведено нагрузочное стресс-тестирование (50–100 одновременных запросов) — 0 ошибок, устойчивая пропускная способность до 113 req/sec.
  - Подтверждена корректная очистка Realtime сокетов (`removeChannel`) во всех экранах для соблюдения лимита 200 одновременных подключений.
- **Оптимизация производительности на мобильных устройствах (устранение фризов):**
  - Устранен спам глубокого клонирования доски и лишних ререндеров при движении пальца (`handleUpdate`).
  - Добавлен мгновенный Guard по активной ячейке (`lastHoveredDropId`) — 0 аллокаций памяти и 0 миллисекунд нагрузки на CPU, пока палец внутри клетки.
  - Проверка допустимости установки фигур переведена на $O(1)$ по предвычисленной матрице.
  - В `BlockGrid` устранены 64 индивидуальные подписки на тему и магазин, вызовы подняты на уровень контейнера.
- **Очистка диска и кэша:**
  - Удалены старые промежуточные архивы и тестовые файлы (освобождено свыше 6 ГБ).
  - Выполнена чистая сборка APK и AAB с предварительным `gradlew clean`.
