## 🎮 Что нового и исправлено

### Сезоны
- **Итоги сезона:** в рекордах появилась кнопка «Итоги прошлого сезона» с финальным топ-10 по Classic, Chaos и Versus.
- **Награды за топ-10:** монеты за место (1-е: 1000, 2-е: 700, 3-е: 500, 4–5-е: 300, 6–10-е: 150, за каждый рейтинг отдельно). Призёры (1–3 места) получают эксклюзивный фон: золотой, серебряный или бронзовый. В магазине эти фоны не продаются.
- **Окно наград:** после закрытия сезона в главном меню один раз показывается, что получено. Награда не теряется, даже если приложение закрыли до зачисления.
- **Титулы:** прошлые места в топ-10 остаются в профиле навсегда («Чемпион · Classic · 2026-09»).
- **Сброс рейтинга Versus больше не молчит:** окно показывает «Рейтинг Versus: 1200 → 600». В конце каждого сезона рейтинг делится пополам.
- **Последний вечер месяца не теряется:** результат, отправленный после полуночи 1-го числа (например, из офлайн-очереди), засчитывается в старый сезон. Закрытие сезона перенесено на 2-е число в 00:05 UTC.

### Durak
- Стол помещается на экране телефона, карты перетаскиваются на iOS (сборка веба, вошла в этот релиз).

## 🛠 Развёртывание (после публикации APK)

1. Миграция `20261020100056_season_rewards_and_grace.sql` уже применена к боевой базе (проверена на тестовых данных в откаченной транзакции). Cron `close-season` теперь работает по расписанию `5 0 2 * *`.
2. **После** загрузки APK в GitHub Releases обновить запись `android_version` в `app_config`:

```sql
UPDATE public.app_config
SET value = jsonb_build_object(
  'latestVersion', '1.0.10',
  'latestBuildNumber', 11,
  'downloadUrl', 'https://github.com/Nerdlin/blockerino/releases/download/v1.0.10/blockerino-1.0.10.apk',
  'releaseNotes', 'Season rewards and results, season titles in the profile, Versus rating reset notice, Durak table fix on phones.',
  'isMandatory', false
)
WHERE key = 'android_version';
```

## ⚠️ Известные ограничения

- Награды и итоги сезона получают только клиенты 1.0.10 и новее; на 1.0.9 они не придут.
- Первое реальное закрытие сезона произойдёт 2 ноября 2026; до этого `close_season()` проверялась только на тестовых данных.
- Сборка подписана **отладочным ключом** (как 1.0.6, 1.0.8 и 1.0.9), ключи `BLOCKERINO_UPLOAD_*` не заданы.
- Окно наград и экран итогов на устройстве вручную не проверялись, веб-версия проверена только в пустом состоянии (закрытых сезонов ещё нет).
