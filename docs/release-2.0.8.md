## 🎮 Что нового

### Вход и аккаунт
- **Вход через Discord в Android-приложении.** Открывается тот же аккаунт, что в Discord Activity, со всеми рекордами и монетами.
- **Плашка «Вы не вошли в аккаунт»** в рейтинге: гость сразу видит, что его рекорды остаются только на устройстве, и может войти одной кнопкой.
- После первого входа рекорды гостя за текущий сезон попадают в сезонный рейтинг.

### Приглашения
- **Дуэль с другом начинается, только когда он принял приглашение.** До этого — окно «Ждём ответа…» с отменой. Если друг отказался или не ответил за минуту, вы сразу это увидите.
- **Того, кто уже играет партию, пригласить нельзя:** игра скажет, что друг сейчас в игре, и не будет его отвлекать.

### Честная игра
- **Рейтинги мини-игр** (шашки, морской бой, дурак, крестики-нолики) меняются по отчёту проигравшего, ничья — по отчётам обоих. Больше нельзя «выиграть» у человека, с которым не играл.
- **Шахматы:** результат без ответа соперника засчитывается только для партии, в которой сервер видел обоих игроков.
- **Дурак на монеты:** банк забирает победитель, только когда все остальные подтвердили проигрыш; иначе ставки возвращаются.
- Заявку в друзья может принять только тот, кому её отправили. Приглашения приходят по закрытому каналу, только от друзей.

### Мини-игры
- **Судоку на компьютере** больше не уезжает за верх экрана.
- **Морской бой:** крупнее поле врага в бою, кнопки не вылезают за край на компьютере, а **в конце игры показываются корабли противника**.
- **Шахматы против бота:** отмена хода стоит 200 монет, подсказка — 50.

### Windows
- Игра для Windows: установщик и версия без установки.

### Под капотом
- **Обновления по воздуху снова работают:** в прошлых сборках Android-приложение не скачивало их. С 2.0.8 исправления доходят до телефона без новой версии в Google Play.

## 🧪 Проверки
- `npx tsc --noEmit` без ошибок, Jest: все наборы тестов, плюс новые тесты входа через Discord, переноса гостевых рекордов и настройки обновлений.
- Проверки базы (`npm run db:check`, Docker): все миграции встают на чистую базу, 24 проверки, в том числе новые на исправления безопасности и админ-панель.
- На телефоне (dev-сборка): вход через Discord в существующий аккаунт, плашка гостя.
