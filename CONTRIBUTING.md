# Как помочь Blockerino

Спасибо, что хотите улучшить игру! Любая помощь приветствуется: баги, идеи, код, переводы, баланс, арт.

## Лицензия коротко

Код остаётся собственностью автора (см. [LICENSE](./LICENSE)), проект не open source. Но вы **можете**:

- сделать форк этого репозитория на GitHub;
- запускать и менять форк у себя, чтобы подготовить вклад;
- отправить pull request в этот репозиторий.

Нельзя использовать форк для других целей: публиковать свою версию игры, деплоить её, выкладывать в магазины, использовать название и ассеты в коммерческих целях, выдавать код за свой. Для этого нужно письменное разрешение автора.

Отправляя pull request, вы соглашаетесь с [CLA](./CLA.md): код ваш, но автор получает право использовать его в проекте, в том числе при смене лицензии.

## Как предложить изменение

1. Для крупных вещей сначала откройте issue или обсуждение (Discussions → Ideas), чтобы не делать работу зря.
2. Сделайте форк и создайте ветку от `main`: `git checkout -b feature/short-name`.
3. Установите зависимости и запустите проект:
   ```bash
   npm install
   npx expo start
   ```
4. Внесите изменения. Придерживайтесь стиля окружающего кода, не смешивайте несколько несвязанных правок в одном PR.
5. Проверьте код перед отправкой:
   ```bash
   npm run lint
   npx tsc --noEmit
   ```
6. Откройте pull request в `main`, заполните шаблон и отметьте согласие с CLA.

## Что приветствуется

- исправления багов (приложите шаги воспроизведения или ссылку на issue);
- переводы и правки текстов;
- улучшения интерфейса и производительности;
- новые идеи по режимам и мини-играм (сначала обсудите).

## Что не будет принято

- изменения секретов, ключей, конфигурации релиза и деплоя (`eas.json`, `.github/workflows`, `supabase/` и т.п.) без согласования;
- код и ассеты, на которые у вас нет прав;
- сторонние зависимости без веской причины;
- правки, меняющие лицензию или авторские уведомления.

## Уязвимости

Не публикуйте уязвимости в открытых issue, смотрите [SECURITY.md](./SECURITY.md).

## Поведение

Будьте вежливы и конструктивны. Токсичные комментарии и спам удаляются, нарушители блокируются.
